description: PR Guide に従ってプルリクエストを作成します
---

以下の手順でプルリクエストを作成してください：

## 手順

1. **ブランチの確認と作成**
   - 現在のブランチが作成した内容と異なる名称の場合、mainブランチから新規ブランチを作成
   - ブランチ命名規則に従う:
     - `feature/*` - 新機能の追加
     - `fix/*` - バグ修正
     - `refactor/*` - リファクタリング
     - `docs/*` - ドキュメント更新
     - `test/*` - テストの追加・修正

2. **変更のコミット**
   - このチャット履歴内で編集したファイルのみをコミット
   - コミットメッセージは以下のルールに従う:
     - 簡潔で明確な日本語で記述
     - 変更の「何を」だけでなく「なぜ」を含める
     - 1行目: 変更内容の要約（50文字以内推奨）
     - 2行目: 空行
     - 3行目以降: 詳細説明（必要に応じて）

3. **PRの作成**
   - `gh pr create`コマンドでプルリクエストを作成
   - タイトルと本文を適切に設定

4. **ブラウザでPRを表示**
   - 作成されたPR番号を取得
   - `gh pr view {pr_number} --web`でブラウザを開く

## 注意事項

- チャット履歴内で編集したファイル以外はコミットしないこと
- PRの説明は変更内容が分かりやすいように記述すること
